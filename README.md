# ☔ Rainfall Analysis 📊

This project provides an analysis of rainfall data across various Indian states using Python and Jupyter Notebook. It explores trends, identifies patterns, and helps derive insights from historical rainfall statistics.

## 📌 Objective

To understand and visualize rainfall trends over the years using statistical methods and data visualization techniques.

## 🛠️ Tools & Technologies Used

- **Language**: Python
- **Notebook**: Jupyter Notebook
- **Libraries**:
  - `pandas` – Data manipulation
  - `numpy` – Numerical operations
  - `matplotlib` – Data visualization
  - `seaborn` – Advanced plotting
  - `plotly` – Interactive charts

## 📂 Dataset

The dataset used contains monthly and annual rainfall data for different Indian states and union territories over multiple years.

## 🔍 Key Analyses Performed

- 📅 Year-wise Rainfall Distribution
- 📍 State-wise Comparison
- 📈 Trendlines and Time Series Analysis
- 🟡 Heatmaps and Boxplots for Distribution
- 🌧️ Identification of Drought/Excess Rainfall Patterns

## 🧪 How to Run

1. **Clone the Repository**
   git clone https://github.com/JustCodeIT199/Rainfall_Analysis.git
   cd Rainfall_Analysis
Set up a Python environment (optional but recommended)
python -m venv env
source env/bin/activate
# On Windows: env\Scripts\activate

Open the Notebook
jupyter notebook Rainfall_Analysis.ipynb
